# Instructions for Connecting to MongoDB Atlas

## Prerequisites
1. MongoDB Atlas account
2. Cluster created in MongoDB Atlas
3. Network access configured (IP whitelist)
4. Database user created with appropriate permissions

## Steps to Connect

1. **Get Your Connection String**
   - Log in to MongoDB Atlas at https://cloud.mongodb.com/
   - Navigate to your cluster (ID: 688af43e8928207b6bc04af9)
   - Click the "Connect" button
   - Select "Connect your application"
   - Copy the connection string

2. **Update Your Credentials**
   - Open the .env file in this directory
   - Replace the placeholder values in the MONGO_URI with your actual:
     - Username
     - Password
     - Cluster details (if different)

3. **Example Connection String Format**
   ```
   MONGO_URI=mongodb+srv://username:password@cluster0.688af43.mongodb.net/
   ```

4. **Security Considerations**
   - Never commit actual credentials to version control
   - Use environment variables or a secure secrets management system
   - Ensure your IP address is whitelisted in MongoDB Atlas

## Running the Connection Test

1. Activate your virtual environment:
   ```
   .\venv\Scripts\activate
   ```

2. Run the test script:
   ```
   python view_atlas_data.py
   ```

## Troubleshooting

### Common Issues:
1. **Authentication Failed**
   - Check username and password
   - Ensure the user has appropriate permissions

2. **Network Issues**
   - Verify your IP is whitelisted in MongoDB Atlas
   - Check firewall settings

3. **DNS Resolution Errors**
   - Ensure you have internet connectivity
   - Check if your network blocks MongoDB connections

4. **Timeout Errors**
   - Increase timeout values in the connection string
   - Check network latency

### Testing Connection Manually:
You can also test the connection using the MongoDB shell or mongosh:
```
mongosh "mongodb+srv://username:password@cluster0.688af43.mongodb.net/"
```
